  1. 단일 이미지 또는 이미지 폴더를 선택합니다.
  2. 필요하면 템플릿 디렉토리와 픽셀 환산값을 설정합니다.
  3. 현재 이미지 또는 디렉토리 전체를 실행합니다.
  4. 필요하면 V홀 crop를 눌러 위치를 보정한 뒤 결과 이미지나 CSV를 저장합니다.
